核心能力

接入之后能拿到什么。

翱翔鸟登录

一键授权，用户不用再记一套新的账号密码。

用户信息

拿到用户唯一 ID、用户名与头像，用来在你的系统里建立关联。

随时可撤销

用户可以在「翱翔鸟账户 → 已授权的第三方应用」里随时收回授权。

三步接入

从注册应用到用户登录成功。

1

注册应用

在开发者控制台创建应用，拿到 Client ID 与 Client Secret。回调地址必须填你真实使用的那一个。

2

引导用户授权

把用户重定向到 /oauth/authorize。未登录的用户会先看到翱翔鸟登录页，登录后自动回到你的授权请求。

3

换取令牌并读取用户

用授权码在服务端换取 access_token，再用它调用 /oauth/userinfo。

接入文档

完整的 OAuth 2.0 Authorization Code 接入指南。

概述

翱翔鸟登录基于 OAuth 2.0 Authorization Code 模式。你的应用把用户重定向到翱翔鸟授权页，用户确认后，翱翔鸟把授权码回调到你的 redirect_uri；你的服务端再用授权码换取 access_token，最后用令牌读取用户信息。整个过程密钥都不经过浏览器。

用户点击「翱翔鸟登录」
   → 跳转 /oauth/authorize
   → 用户确认授权
   → 回调你的 redirect_uri，带 ?code=...&state=...
   → 服务端 POST /oauth/token 换 access_token
   → 服务端 GET /oauth/userinfo 读用户信息

第一步：注册应用

在开发者控制台创建应用，你会得到 client_id 与 client_secret。创建时需要填：

  • 应用名称 — 显示在用户看到的授权确认页上
  • 回调地址（redirect_uri） — 必须精确匹配，含协议、域名与路径
  • 应用描述（选填）— 一句话说明你的应用做什么
  • 主页地址（选填）— 你的应用主页
client_secret 只能放在服务端，绝不能出现在前端代码或客户端二进制里。万一泄露，在控制台点「重置密钥」即可，Client ID 不会变，已接入的配置不用改。

第二步：引导用户授权

把用户重定向到授权端点：

GET/oauth/authorize

参数：

参数必填说明
client_id是你的应用 Client ID
redirect_uri是授权回调地址，必须与注册时一致
response_type是固定为 code
scope否权限范围，目前只支持 userinfo（默认）
state建议随机字符串，防 CSRF，回调时原样返回

示例：

https://论坛域名/oauth/authorize?client_id=你的client_id&redirect_uri=https://yourapp.com/callback&response_type=code&scope=userinfo&state=abc123

用户点「允许」之后，翱翔鸟跳转回你的回调地址：

https://yourapp.com/callback?code=授权码&state=abc123

用户点「拒绝」时：

https://yourapp.com/callback?error=access_denied&state=abc123
用户未登录时不会跳回论坛首页，而是直接进入翱翔鸟登录页；登录成功后会自动回到这次授权请求，用户不需要重新点一次登录。

第三步：用授权码换取令牌

在你的服务端发起请求：

POST/oauth/token

请求体（application/x-www-form-urlencoded）：

参数必填说明
grant_type是固定为 authorization_code
code是上一步拿到的授权码
client_id是你的应用 Client ID
client_secret是你的应用 Client Secret
redirect_uri是与授权请求中一致的回调地址

成功响应：

{
  "access_token": "生成的访问令牌",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "userinfo"
}

失败响应：

{ "error": "invalid_grant", "error_description": "授权码已过期" }
授权码 5 分钟内有效，且只能使用一次。拿到 code 就要立刻换取令牌，不要缓存。

第四步：读取用户信息

带上访问令牌请求用户信息端点：

GET/oauth/userinfo

请求头：

Authorization: Bearer <access_token>

成功响应：

{
  "id": "u_xxxxx",
  "username": "用户名",
  "avatar": "/uploads/avatars/xxx.png"
}

id 是用户在翱翔鸟平台的唯一标识，建议用它作为你系统里关联翱翔鸟账号的键值。访问令牌有效期 1 小时，过期后需要用户重新走一次授权。

错误码

错误码HTTP说明
invalid_request400缺少必要参数，或 redirect_uri 与注册值不匹配
invalid_client401client_id 或 client_secret 无效
invalid_grant400授权码无效、已使用或已过期
invalid_token401access_token 无效或已过期
unsupported_grant_type400不支持的 grant_type
access_denied—用户拒绝授权，通过 redirect_uri 回调

完整示例

Python（Flask）：

from flask import Flask, redirect, request, session
import requests

app = Flask(__name__)
app.secret_key = '换成你自己的随机字符串'

CLIENT_ID = '你的 client_id'
CLIENT_SECRET = '你的 client_secret'
REDIRECT_URI = 'https://yourapp.com/callback'
SB_BASE = 'https://你的论坛域名'


@app.route('/login')
def login():
    state = '随机字符串'
    session['oauth_state'] = state
    return redirect(f'{SB_BASE}/oauth/authorize?client_id={CLIENT_ID}'
                    f'&redirect_uri={REDIRECT_URI}&response_type=code'
                    f'&scope=userinfo&state={state}')


@app.route('/callback')
def callback():
    if request.args.get('error'):
        return f"授权被拒绝：{request.args.get('error')}", 400

    code = request.args.get('code')
    state = request.args.get('state')
    if state != session.get('oauth_state'):
        return 'State 不匹配', 400

    token = requests.post(f'{SB_BASE}/oauth/token', data={
        'grant_type': 'authorization_code',
        'code': code,
        'client_id': CLIENT_ID,
        'client_secret': CLIENT_SECRET,
        'redirect_uri': REDIRECT_URI,
    }).json()
    if 'access_token' not in token:
        return f"换令牌失败：{token}", 400

    user = requests.get(f'{SB_BASE}/oauth/userinfo', headers={
        'Authorization': f"Bearer {token['access_token']}"
    }).json()

    # user = {"id": "u_xxx", "username": "xxx", "avatar": "/uploads/..."}
    # 用 user['id'] 关联你自己系统的账号
    return f"欢迎，{user['username']}"
